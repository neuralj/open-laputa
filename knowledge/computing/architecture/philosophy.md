# Architecture Philosophy

## 1. Start Small

从能表达问题的最小结构开始。

## 2. Grow by Evidence

只在真实复杂度出现时才增加结构。

## 3. Prefer Locality

保持相关行为就近放置。

## 4. Delay Abstraction

不为假设性复用创建抽象。

## 5. Architecture Is a Constraint

架构的存在是为了约束未来变化，不是预测所有未来需求。

## 6. Agent-Compatible Structure

优先选择显式的、局部的、Agent 可检查和修改的结构。

# Computing

计算领域的认知体系。

## 核心命题

> **Cognition as Code** — 将人类工程认知转化为 Agent 可消费、可执行、可验证的结构化知识。

## 四个层次

| 层次 | 含义 | 本 repo 体现 |
|------|------|-------------|
| Knowledge as Code | 认知本身 | philosophy, principles |
| Constraint as Code | 约束规则 | layers, dependencies |
| Contract as Code | 人机契约 | skeletons, units |
| Infrastructure as Code | 基础设施声明 | 未来方向 |

## 哲学概括

```
隐性认知
    ↓
显式结构化（Cognition as Code）
    ↓
Agent 可消费
    ↓
代码生成
    ↓
基础设施声明（Infrastructure as Code）
    ↓
现实系统
```

## 与传统 AaC 的区别

| 传统 Architecture as Code | 本体系 |
|---------------------------|--------|
| 描述某个系统是什么样的 | 编码系统应该如何被构建 |
| Model → Diagram | Philosophy → Skeleton → Layer |
| Human → Code | Agent → Code → Verification |
